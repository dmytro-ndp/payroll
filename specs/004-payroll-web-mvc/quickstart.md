# Quickstart: перевірка вебінтерфейсу (задача 004)

## Передумови
- JDK 21, Maven; вільний порт 8080; для оформлення сторінки — доступ до CDN Tailwind.

## Запуск
```bash
mvn clean compile
mvn exec:java
```
Очікується повідомлення про запуск вебсервера; ввід у консолі не потрібен; зупинка — Ctrl+C.
Файл `target/employees.html` не створюється.

## Автоматична самоперевірка моделі й вигляду
```bash
mvn exec:java "-Dexec.mainClass=ua.payroll.SelfCheck"
```

## Перевірка API (див. [contracts/rest-api.md](contracts/rest-api.md))
| Крок | Команда | Очікування |
|------|---------|------------|
| 1 | `curl -i localhost:8080/api/Payroll` | 200, `{"employees":[]}` на порожній БД |
| 2 | `curl -i -X POST localhost:8080/api/Payroll -H "Content-Type: application/json" -d "{\"employeeId\":\"E1\",\"fullName\":\"Іван Петренко\"}"` | 201 |
| 3 | той самий запит повторно | 400 (дублікат) |
| 4 | POST із `"fullName":"   "` або порожнім тілом | 400 |
| 5 | `curl -i -X PUT localhost:8080/api/Payroll/E1 -H "Content-Type: application/json" -d "{\"fullName\":\"Новий ПІБ\"}"` | 200 |
| 6 | PUT `/api/Payroll/E1` з `"employeeId":"E2"` у тілі | 400 |
| 7 | PUT/DELETE `/api/Payroll/NOPE` | 404 |
| 8 | `curl -i -X DELETE localhost:8080/api/Payroll/E1` | 200 |

## Перевірка сторінки (`http://localhost:8080/`)
1. Таблиця порожня на новій БД; після додавання через форму з'являється рядок і зелене/синє повідомлення про успіх.
2. «Змінити» переносить рядок у форму: `employeeId` лише для читання, є «Скасувати»; після збереження форма — у режимі додавання.
3. «Видалити» питає підтвердження; повідомлення лишається до наступного.
4. Дублікат або порожнє поле — повідомлення про відмову іншого оформлення.
5. Перезапуск програми — усі збережені працівники на місці.
6. Нечинний наказ (змінити `ORDER-001` на відкликаний у `Main` для експерименту) → 409 на будь-яку зміну.
7. Зайнятий порт 8080 — зрозуміле повідомлення в консолі.
